# 辯論社課手帳

辯論社的社課講義網站。每週一堂，把辯論拆成看得懂、練得會的小單元。

- 網站：https://chungen0927-gif.github.io/debate-notes/
- 專案規則：[AGENTS.md](./AGENTS.md)

## 這個專案在做什麼

這不是一頁一頁手工做出來的網站，而是一套「規則 ＋ 範本」：

1. `AGENTS.md` 說明專案目的、檔案結構、講義的固定格式、可用元件、內容來源、文字與視覺風格，以及新增講義的步驟。
2. `templates/lesson.html` 是每一堂講義的範本。
3. `assets/lessons.js` 是講義清單，首頁卡片與上下堂連結都由它自動產生。
4. `tools/check.mjs` 會檢查新講義是否符合規則。

講義內容來自講師每次社課的簡報。所以要新增一堂課，只需要把簡報交給 AI 並說：

> 請依 AGENTS.md 把這份簡報做成下一堂講義。

AI 就會複製範本、依簡報撰寫內容、登記到清單，並執行檢查。

## 檔案結構

```
├── AGENTS.md          專案規則（給 AI 讀）
├── CLAUDE.md          指向 AGENTS.md
├── index.html         首頁
├── assets/            樣式、講義清單、共用程式
├── lessons/           每堂講義一個檔案
├── templates/         講義範本
└── tools/check.mjs    檢查腳本
```

## 本機預覽與檢查

不需要安裝任何東西，用瀏覽器直接打開 `index.html` 即可預覽。

```
node tools/check.mjs
```
